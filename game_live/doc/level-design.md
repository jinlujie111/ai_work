## 一、规则速查

所有关卡共用下面这一套规则，关卡之间只改「地图、时长、动物、资源、目标、星星条件」。

| 规则 | 内容 |
| --- | --- |
| 操作 | 单指按住拖动，角色朝手指位置移动，最大偏移 120 像素，松手停下。没有其他按键。 |
| 目标 | 每关收敛成一句话，完成即过关。资源是手段，不是目标。 |
| 采集 | 走到资源上自动采集，耗时 0.8 秒，拾取半径 28。被熊惊动会中断，资源不消失。 |
| 体温 | 上限 100。白天不变，夜里火堆内每秒 +6、火堆外每秒 -2.5，归零即失败。 |
| 火堆 | 位置固定不可移动，保温半径 180，每 10 秒烧掉 1 根木头，熄灭后不再回温。 |
| 木头 | 采到后必须送到火堆才生效，没有背包，走过去自动交付。 |
| 药草 | 解除蛇毒。 |
| 熊 | 巡逻到警觉到追击到搜索。感知 260，视锥 90 度，接触 34 即被抓。 |
| 蛇 | 完全静止伏击，触发半径 46，咬击延迟 0.4 秒，中毒扣 30 体温、3 秒后自解。 |
| 兔 | 300 像素内逃跑，捕获得 2 分，被抓在手里可以引开追击中的熊 4 秒。 |
| 昼夜 | 白天视野全开，夜里视野缩到 320 像素圆形，外侧亮度 25%。 |
| 星级 | 每关三条，达成型条件；第一条「完成主目标」必选。 |
| 失败 | 体温归零、被熊抓���、超时未达目标。 |
