## 0. 一句话定义

**cozy-lite survival** = 有真实生存压力的轻度关卡游戏，但压力可控、短局可承受、视觉与文案偏温暖。

| 对照 | 硬核生存 | 本项目（改造后） | 完整 cozy survival |
|---|---|---|---|
| 压力 | 很强 | 有，短局可承受 | 弱，偏治愈 |
| 单局 | 长 | 60–120 秒 | 数小时 |
| 操作 | 多系统 | 仍只有拖动 | 采集/建造/剧情齐全 |
| 感知 | 「求生」 | 「舒服地挨过一夜」 | 「过日子」 |

**不可动摇：**

1. 仍然只有一个操作：单指拖动。
2. 仍然只有一个目标：活到天亮。
3. 深度仍只加在移动上（模式识别 / 风险定价 / 时间压力）。
4. 不新增背包、技能栏、建造、养成。

## 1. 产品切面

同一套核心，两个呈现切面（与现有 cn / global scope 对齐）：

| 项 | 国内切面（微信 / 抖音） | 海外切面（itch / Steam） |
|---|---|---|
| 对外品类语感 | 轻度生存闯关 | Cozy-lite survival |
| 单局 | 60–120 秒 | 同左 |
| 广告 | 可有（复活限 1 次等） | 无 |
| 图鉴 / 每日挑战 | 可后置 | Steam 必做（厚度） |
| UI 气质 | 与海外同气质，禁止土味超休皮 | 安静、暖光、少数据噪音 |
| 商店句 | 单指拖动，活到天亮 | Survive the night in a quiet forest — one thumb, one dawn |

国内版可以短、可以有广告，但**视觉与失败语气必须跟 Steam 同温**，避免一套玩法两副面孔。

## 2. 气质规则（最高优先级）

### 2.1 失败

| 项 | 旧 | 新 |
|---|---|---|
| 文案 | 失败 / 被抓 / Game Over | 「今晚没撑住」/「天还没亮」 |
| 视觉 | 强红闪、重抖动 | 轻暗角 + 短促暖色收束；抖动幅度减半 |
| 音频 | 惊吓闷响 | 下行柔和音 + 风声，避免尖叫感 |
| 重试 | 标准按钮 | 「再试一夜」；进入下一局无惩罚等待 |

规则仍是体温归零或被熊接触即失败，**判定不变，观感变软**。

### 2.2 威胁的拟人化

| 对象 | 旧读法 | 新读法 |
|---|---|---|
| 熊 | 追击怪物 | 有领地的动物；行为可预测 |
| 蛇 | 陷阱惊吓 | 草丛里的伏击者；嘶声是预警不是惊吓秀 |
| 兔 | 道具 | 林中伙伴 / 可利用的机缘 |
| 火堆 | 数值回温点 | 夜里唯一的家 |

熊的警觉优先用脚步、灌木晃动、低吼；**少用全屏血红**。接触死亡保留，但死亡演出不做成恐怖游戏。

### 2.3 HUD 语义

数值结构可保留（体温、倒计时、目标、星星），语义重命名：

| 系统名 | 界面呈现（中） | 界面呈现（英） |
|---|---|---|
| 体温 | 温暖 | Warmth |
| 倒计时（昼） | 离黄昏 | Until dusk |
| 倒计时（夜） | 离天亮 | Until dawn |
| 关卡 | 第 N 夜 · 名称 | Night N · Name |
| 分数 | 次要，小号 | 次要，小号 |

**原则：** HUD 像环境仪表，不像闯关数据板。禁止在首屏堆活动条、礼包入口、闪烁促销。

### 2.4 结算

| 元素 | 要求 |
|---|---|
| 成功标题 | 「天亮了」/ Dawn |
| 失败标题 | 「今晚没撑住」/ Not this night |
| 正文 | 一句本夜摘要（图标化即可，如：火堆未灭 · 引开熊 1 次） |
| 三星 | 保留；空心星不闪红 |
| 图鉴 | 若本夜首次触发耦合/机制，结算页给一枚静默解锁提示 |
| 按钮 | 再试一夜 / 下一夜 / 分享（国内） |

## 3. 关卡叙事包装

### 3.1 命名

对外不再强调「第 37 关」，统一为：

**`第 {n} 夜 · {诗意短名}`**

| 章 | 章节名 | 夜次 | 示例夜名 |
|---|---|---|---|
| 1 | 林缘 | 1–10 | 学会移动 → 可保留教学名；第 10 夜「林缘的夜」 |
| 2 | 深处 | 11–20 | 学会蛇、夜路、双熊… |
| 3 | 水岸 | 21–30 | 水边、夜渡… |
| 4 | 猎场 | 31–40 | 领地、引熊出洞… |
| 5 | 深冬 | 41–50 | 严寒、归途… |

实现：`levels.js` 增加 `nightTitle`（或复用现有 `name` 字段，展示层加「第 N 夜」前缀）。`level-design.md` 由生成器同步「夜」称谓。

### 3.2 章节过场

每章进入时：

- 一张静帧插画（或程序化色块 + 地标剪影）
- 一句环境旁白（可无字，用天气/色温表达）
- 时长 ≤ 2.5 秒，可跳过

目的：把「刷关」感改成「在林子里过了一周」。

### 3.3 每夜一个小秘密（设计约束）

第 5 夜起，每夜至少具备下列之一（配置标记，不做教程）：

- 一条可发现的捷径或掩体用法
- 一只非常规位置的兔子 / 金浆果
- 一个仅夜间可读的环境信号（光、蛙鸣预留位等）

秘密服务「发现感」，不新增操作。

## 4. 压力节奏（可控的紧张）

数值大框架不变，节奏约束如下：

| 阶段 | 时长感 | 设计意图 |
|---|---|---|
| 白天 | 主体时间 | 观察、采集、走位练习；压力低 |
| 黄昏过渡 | **5–8 秒** | 光线渐暗、色温偏冷、音频交叉淡入；禁止硬切全黑 |
| 夜晚 | 短而尖 | 维持约 30 秒量级；检验白天准备 |
| 火堆旁 | 明确安全 | 暖光可读、回温可读；熊不主动扑入保暖半径（已有则强化表现） |

**风险定价保留，但频率收敛：**

- 金浆果仍只在危险区。
- 多数夜允许「安全通关也舒服」；三星才鼓励贪。
- 不靠每夜都逼极限贪心制造难度。

舒适感来源：**玩家多数时间觉得局面可控，偶尔主动冒险。**

## 5. 加厚度（仍只有拖动）

### 5.1 图鉴（海外首发必做，国内可同版隐藏入口）

| 项 | 规格 |
|---|---|
| 解锁条件 | 首次观察到对应现象（兔引熊、蛇伏击、火堆回温、树丛遮挡等） |
| 单条内容 | 剪影 + 参与方 + 一句话关系 +「可利用 / 需规避」图标 |
| 数量（首版） | 5–8 条，覆盖已实装机制 |
| 禁止 | 长文攻略、强制阅读才能过关 |

### 5.2 每日一夜（海外）

- 当日种子一局；目标 survive 或轻量 score。
- 与主线共用规则，不新操作。
- 国内可后置。

### 5.3 明确不做（改造阶段）

建造、背包、技能、体力系统、赛季、复杂天气（天气仍按原第二阶段）、跨关长期惩罚。

## 6. 音频与美术补充

在 `game-design-spec.md` 第七、八章基础上追加气质约束：

| 项 | 要求 |
|---|---|
| 主色 | 苔绿、暖褐、火堆橙；夜间青灰但不发「恐怖紫」 |
| 火堆 | 双层火苗 + 暖半径可视，是情感锚点 |
| 受击 | 轻红闪可选；默认优先暗角与短暂停顿 |
| 昼夜 BGM | 鸟鸣 → 风虫交叉淡入；无突变 drop |
| 成功 | 上行三音保持；音色更清亮温暖 |
| 失败 | 柔和下行，不刺耳 |

美术风格仍是扁平几何 + 轻体积；**暖、静、可读**优先于炫技光效。

## 7. Steam / itch 包装

| 项 | 内容 |
|---|---|
| 英文名（工作名） | Nightfall Forest |
| 定位句 | Survive the night in a quiet forest — one thumb, one dawn |
| 标签 | Cozy, Survival, Casual, Relaxing, Short sessions, Animals, Singleplayer |
| 截图优先级 | ① 火堆暖光 ② 树影潜行 ③ 兔子引开熊的 aha ④ 天亮结算；少放密 HUD |
| 时长承诺 | 一局 1–2 分钟；一章约半小时 |
| 定价 | 内容薄：$2.99–4.99；五章 + 图鉴 + 每日齐备可试 $6.99–9.99 |
| 路径 | itch 体验版攒反馈 → Steam 商店页与愿望单 |

**禁止**在 Steam 页使用「hyper-casual / 超休闲 / 三秒上手点点点」作为主卖点话术；短局说成 short sessions，不说 junk food。

## 8. 验收（气质向，补充 A 清单）

在原 A1–A12 之外增加：

| 编号 | 验收项 | 通过标准 |
|---|---|---|
| C1 | 失败不凶 | 测试者描述失败感受时，不出现「吓人/恶心」为主词 |
| C2 | 重试意愿 | 失败后 10 秒内主动重试比例高于 70% |
| C3 | 夜名称 | 玩家能说出「第几夜」而非只记得关卡数字 |
| C4 | 黄昏可读 | 不看教程也能感到「快入夜了」 |
| C5 | 火堆安心 | 入夜后主动靠近火堆的比例高于 60%（有火堆的关） |
| C6 | Steam 截图 | 去掉 UI 后仍能辨认是森林暖夜，而非通用超休 |
