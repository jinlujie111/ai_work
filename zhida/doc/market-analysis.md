## 1. 形态判断

本产品落在 **L4 学习目标规划 Agent**：管学习目标实现过程（模块→任务→执行），不是 AI 待办。

| 层级 | 代表 | 与本产品关系 |
|------|------|------------|
| L1 任务记录 | 滴答清单 / Todoist | 能力重叠，非主战场 |
| L2 习惯打卡 | 小习惯 / Fabulous | 场景子集 |
| L3 AI 日程调度 | Motion / Reclaim / Sunsama | 强「何时做」，弱「如何拆」 |
| **L4 学习/目标规划 Agent** | **本产品 / Goaltree / 知行清单 / 可米** | **直接竞争** |
| L5 垂直闭环 | 多邻国 / Keep | 单场景完成率更强 |

**结论：** 方向正确，但非蓝海。胜负看重规划质量与 7 日留存，不看「会不会拆目标」。

## 3. 可防守差异（建议押注）

1. **偏差诊断引擎**：归因（时间/难度/前置/优先级），不是整日顺延  
2. **计划版本账本**：调整前后 diff + 回滚  
3. **用户技能档案**：与目标分离、程度可确认、跨目标复用（P1 起）  
4. **垂直模板深度**：先打穿 Python / 英语 / 健身等 1–2 场景  
5. **微信获客闭环**：补小程序触达短板  

**不要当壁垒：** 会调用大模型拆目标、有 AI 对话页、有周报、口号比滴答更智能。

---

## 4. MVP 验证焦点

只验证：

```text
创建目标 → 确认计划 → 连续 7 天执行 → 至少 1 次接受重规划
```

调整接受率低 → 叙事塌成 AI 待办；7 日留存差 → 再堆语音/会员意义不大。
