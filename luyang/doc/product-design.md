# 拼车狂飙 · 产品设计文档

> 微信小游戏 / H5（可后接双端）  
> **产品名：拼车狂飙**（拼 = 拼装，不是网约拼车）  
> **推广语：别人撞车 Game Over，你撞车越撞越大**  
> 定位：**局内公路拼装** + **局外道具合成 / 车阶成长 / 商城**  
> 工程目录仍为 `luyang`；旧「路养」见 [`product-design-luyang-v1.md`](./product-design-luyang-v1.md)

## 1. 双层结构（必须分清）

| 层 | 玩家在干什么 | 产出 | 是否跨关保留 |
|----|--------------|------|----------------|
| **局内** | 变道、撞/躲、窄路丢临时零件、**释放当前车型技能** | 星级、金币、本关掉落的**持久道具** | 临时拼装**不**带入下一局 |
| **局外** | 背包、合成、商城买卖、升车阶 | 道具库存、当前载具、乘客位、**车型技能** | **全部保留** |

原则：
- 局内「废铁吸附」负责**爽感和反常识**（可见宽/长）。  
- 局内「车型技能」负责**换车有手感差异**（每台车技能不同）。  
- 局外「道具 1～30 + 车阶 1～30」负责**长线目标**。  
- 用「关卡掉落等级」和「升车消耗道具」把两层钉在一起。

## 2. 方向判断

| 维度 | 判断 |
|------|------|
| 局内创新 | 仍以撞装为主；验收看会不会主动撞、主动丢 |
| 局外循环 | 星级金币 → 商城 / 合成 → 更高车阶 → 打更高关 → 更高阶掉落 |
| 实现节奏 | 先 60s 撞装手感 → 再接星级与 L1 掉落 → 再接合成与自行车升阶 |
| 个人主体 | 金币经济可先全免费；变现仍以激励视频（双倍金币/复活）为主 |
| 风险 | 30 级道具 × 30 车阶内容量大 → **数值用公式生成**，美术用换色/部件组合，不手写 900 种 |

## 3. 局内核心循环（拼装）

```text
左右变道前进
  → 撞可吸废铁（临时零件，改变宽/长/速）
  → 按需点「车型技能」（冷却 / 次数限制）
  → 窄路：丢临时件 or 硬闯 or 用技能过
  → 沿途拾取/撞出「关卡掉落道具」（进背包，持久）
  → 到站：按表现定 三星 / 二星 / 一星 → 发金币 + 结算掉落
```

单局时长目标：**60～90 秒**。  
临时零件见 §6；持久道具见 §7；车型技能见 §9.5。

## 4. 操作与胜负

| 项 | 规则 |
|----|------|
| 操作 | 自动前进 + 左右变道；可暂停 |
| 失败 | 致命碰撞且无防撞；断桥；过热熄火（若有）等 |
| 成功 | 到达本关终点 → 进入**星级结算**（失败也可发安慰金币，但不给星、少掉落） |

## 5. 星级结算与金币

每关通关后评定 **三星 / 二星 / 一星**（未通关 = 0 星）。  
星级决定**本关金币**；掉落道具件数可随星级小幅加成。

### 5.1 星级标准（草案，可调）

| 星 | 条件（同时满足或按权重表，实现时二选一写死） |
|----|----------------------------------------------|
| ★★★ | 通关 + 用时 ≤ 三星时限 + 窄路未硬闯失败过 + 临时件完整度 ≥ 阈值 |
| ★★ | 通关 + 未达成三星条件 |
| ★ | 通关但触发过复活 / 完整度很低 / 超时较多 |
| 无星 | 未到达终点 |

> 第一版可用简化版：**三星=无伤通关且较快；二星=正常通关；一星=通关但用过复活或多次撞掉件。**

### 5.2 金币表（草案）

设关卡序号为 `N`（从 1 起），基础金币 `G = 20 + 8 × N`：

| 星级 | 金币 |
|------|------|
| ★★★ | `G × 1.5`（取整） |
| ★★ | `G × 1.0` |
| ★ | `G × 0.6` |
| 失败 | `G × 0.15`（安慰奖，可关） |

激励视频：**双倍本关金币**（个人主体优先）。

### 5.3 历史星级

- 每关记录**历史最高星**；重复刷关：金币仍发，但「首达三星」可另给一次额外奖励。  
- 选关界面展示每关 ★★★ 亮暗。

## 6. 局内临时零件（撞装，不进商城）

与持久道具分开命名，避免混淆。

| id | 名称 | 可见变化 | 能力 | 代价 |
|----|------|----------|------|------|
| `bumper` | 防撞杠 | 车头多杠 | +1 次防撞 | 略变长 |
| `wide_tire` | 宽轮胎 | 变宽 | 颠簸更稳 | 更难过窄路 |
| `crate` | 货箱 | 变长/堆箱 | 本关星级判定加分 | 转向钝 |

规则：吸附、窄路丢弃、形态=规则（同前版）。  
**临时零件通关后清空**，不进入背包，不可出售。

## 7. 持久道具（1～30 级）

### 7.1 定义

- 道具有 **等级 Lv1～Lv30**。  
- 同名同级可堆叠。  
- **合成：** `2 个相同的 LvN` → `1 个 Lv(N+1)`（N&lt;30）。  
- 用途：  
  1. **升车阶**（主消耗）  
  2. 商城出售换金币  
  3. （可选）局内开局带 1 个「挂载加成」——MVP 可不做，先只用于升车与买卖  

### 7.2 合成

```text
背包选中某道具
  → 若同级同名数量 ≥ 2
  → 点合成：消耗 2，获得 1 个高一级
  → 可连续合成（提供「一键合成到最高」需确认，防误触）
```

合成**不收费**（或收极少金币）；主要摩擦在「掉落与关卡进度」。

### 7.3 关卡掉落等级（每 5 关一阶）

每关局内配置 **若干可拾取/可撞出的持久道具点**（建议 3～6 个），掉落等级由关卡区间决定：

| 关卡区间 | 掉落道具等级 | 说明 |
|----------|--------------|------|
| 1～5 | Lv1 | 新手期 |
| 6～10 | Lv2 | |
| 11～15 | Lv3 | |
| 16～20 | Lv4 | |
| … | … | 每 5 关 +1 级 |
| `5×(K-1)+1` ～ `5×K` | **Lv K** | K = 1～30 |
| 146～150 | Lv30 | 满级掉落段 |

公式：`dropLevel = ceil(stageId / 5)`，上限 30。

**星级对掉落件数（草案）：**

| 星 | 本关掉落件数 |
|----|----------------|
| ★★★ | 基础件数 + 1（或稀有率提升） |
| ★★ | 基础件数 |
| ★ | 基础件数 - 1（至少 1） |
| 失败 | 0～1（极少） |

基础件数建议：前 10 关 3 个，之后 4～5 个。

> 用户原文「5～10 关掉二级」与「前 5 关一级」在第 5 关交界；本文采用 **1～5→Lv1，6～10→Lv2**，避免同一关掉两级混乱。若需第 5 关起掉 Lv2，改公式为 `dropLevel = ceil((stageId+4)/5)` 即可，实装前定一版冻结。

## 8. 商城

### 8.1 买

- 用**金币**购买持久道具（按等级标价）。  
- 草案价：`buyPrice(Lv) = 30 × 2^(Lv-1)`（Lv 高时改为分段线性，防止爆炸；实现时 Lv1～10 用指数，Lv11+ 改缓增）。  
- 商城货架：常驻当前「进度附近」等级（如最高通关关卡对应 dropLevel ±1），避免一开局卖满级。

### 8.2 卖

- 背包道具可卖到商城。  
- **折价 50%：** `sellPrice = floor(buyPrice × 0.5)`。  
- 卖出不可撤销（二次确认）。

### 8.3 商城不卖

- 不直接卖「满级车」（车只能靠道具升阶）。  
- 不卖临时撞装件。  
- 避免开箱随机（个主体审核与体验）。

## 9. 车阶 1～30、乘客与车型技能

### 9.1 定义与开局（已冻结）

- 玩家拥有**当前车阶** `V = 1～30`（同时只开一辆主力车）。  
- 车阶决定：模型、基础速度、碰撞体积基准、**乘客座位数量**、**专属主动技能**、可挑战关卡上限（可选）。  
- **开局定案：赠送 V1 自行车**，无需消耗道具合成；玩家进游戏即可开第一关。  
- 升到 V2 及以后：严格按 §9.3 消耗表。  
- 自行车座位：**仅 1 名乘客**。

### 9.2 车阶列表示意（1～8 写名，其后公式）

| 车阶 V | 名称（示意） | 乘客位 | 升到本阶消耗（从 V-1） |
|--------|--------------|--------|------------------------|
| 1 | 自行车 | 1 | **开局赠送（已冻结）** |
| 2 | 电动车 | 1 | 按 §9.3 |
| 3 | 摩托车 | 1 | 按 §9.3 |
| 4 | 三轮摩托车 | 2 | 按 §9.3 |
| 5 | 微型轿车 | 2 | |
| 6 | 轿车 | 3 | |
| 7 | SUV | 4 | |
| 8 | 皮卡 | 4 | |
| … | 面包车 / 巴士 / 卡车 / 牵引车 / … | 递增 | |
| 30 | 终极载具（命名待定） | 上限封顶（如 8） | 按 §9.3 |

名称 9～30 用题材表批量命名即可。

### 9.3 升阶消耗（统一公式，草案）

从 `V` 升到 `V+1`：

```text
需要：2 个「等级 = min(V+1, 30)」的持久道具
（与道具合成同构：越高级车吃越高级料）
```

V1 自行车不消耗；无「1×Lv2 合成自行车」流程。

### 9.4 车阶对局内的被动影响（可见）

| 车阶升高 | 玩家看见 |
|----------|----------|
| 模型更换 | 自行车 → 电动车 → 摩托… |
| 速度基准↑ | 更快到站（利于三星时限） |
| 乘客位↑ | 结算座位加分（MVP 简单加分即可） |
| 体积基准↑ | 更高阶默认更宽，窄路更刁 |
| **技能更换** | HUD 技能键图标/名称随车型变 |

### 9.5 车型主动技能（闯关可释放）

**定案：每个车阶拥有 1 个互不相同的主动技能**；进入关卡后可手动释放，用于过险、抢星或保命。

#### 释放规则（全局）

| 项 | 规则 |
|----|------|
| 入口 | 局内 HUD 固定「技能」键（小游戏触控 / H5 按钮；键盘可用 `Space` 或 `F`） |
| 冷却 | 每车技能自带 `cooldown` 秒；CD 中按钮置灰 |
| 次数 | 可选 `charges`（如本关 2 次）；无 charges 则仅 CD |
| 暂停/事件 | 检查点选丢件、暂停界面时不可放 |
| 与临时件 | 技能不替代撞装决策；可与临时件叠加（如先吸宽胎再放「侧倾过窄路」） |
| 可见反馈 | 必须有动作/特效/车身变化，禁止只跳数字 |
| 失败救援 | 技能不是无敌；放完仍可能撞死 |

#### 前 8 阶技能表（草案，可调数值）

| V | 车型 | 技能名 | 效果（局内） | CD / 次数 | 设计意图 |
|---|------|--------|--------------|-----------|----------|
| 1 | 自行车 | 铃响闪身 | 0.8s 内可穿过**一个**非致命障碍（无敌帧极短） | 12s / 关 3 次 | 教学：技能=主动决策 |
| 2 | 电动车 | 电门催速 | 3s 内速度 ×1.35，过热微涨（若有） | 14s | 抢三星时间 |
| 3 | 摩托车 | 压弯变道 | 立刻完成一次变道且短暂缩窄碰撞盒 | 10s | 贴脸抢废铁 |
| 4 | 三轮摩托 | 稳坨 | 2.5s 内不受颠簸/侧滑，宽胎惩罚减半 | 16s | 宽车保命 |
| 5 | 微型轿车 | 喇叭清道 | 前方短距小型障碍弹开（不可清致命大件） | 18s / 关 2 次 | 清道 vs 留物 |
| 6 | 轿车 | 安全带 | 抵消下一次非致命猛撞（不耗防撞杠） | 20s | 容错 |
| 7 | SUV | 越野胎 | 5s 内可轧过路肩草皮（多一条「旁路」） | 22s | 绕开窄路 |
| 8 | 皮卡 | 卸货 | 立刻丢掉 1 个临时货箱类零件并前冲 | 15s | 主动瘦身 |

V9～V30：按模板批量填——`爆发加速 / 护盾 / 清障 / 瞬移变道 / 缩窄 / 吸铁范围增大` 等原型轮换，**同名效果不重复占两个相邻车阶**。完整表另册 `vehicle-skills.md` 实装时展开。

#### 技能与星级

- 使用技能**不扣星**（鼓励用）。  
- 若某关「三星条件含不使用技能」——**不做**（与「技能是车型身份」冲突）。  
- 可用技能创造三星（催速赶时限、闪身少受伤）。

#### MVP 范围

- P0：至少实现 **V1 铃响闪身**（开局自行车必可用）。  
- P1：V2～V4 技能随升阶解锁。  
- P2：补全至 V8；再公式生成 V9～30。

## 10. 关卡设计要点

| 要点 | 规则 |
|------|------|
| 每关道具 | 配置 3～6 个**持久道具掉落点**（等级=§7.3） |
| 每关临时废铁 | 另有 absorb 件，负责撞装手感 |
| 检查点 | ≥1 次窄路/丢件（教学关可极宽） |
| 进度门 | 建议：车阶 `V` 可打关卡 `≤ 5×V`（可调）；或仅星级解锁下一关 |
| 解锁 | 通关第 N 关解锁 N+1；与车阶门可同时存在 |

前 5 关：只掉 Lv1，教学撞装 + 第一次 ★★★ + 第一次进商城/合成。

## 13. 60 秒 / 长线验收

### 13.1 局内（创新）

同前：主动撞、愿变钝、窄路愿丢、能说出「要不要撞」。

### 13.2 局外（成长）

| # | 行为 | 通过 |
|---|------|------|
| 1 | 看懂三星比一星金币多 | 会重刷刷星 |
| 2 | 会合成 2×Lv1→Lv2 | 无引导也能点 |
| 3 | 会卖多余件（接受 50%） | 缺钱时卖 |
| 4 | 会为升电动车攒材料 | 有明确下一目标 |
| 5 | 知道高关掉高等级道具 | 选关看掉落预告 |
| 6 | 会在关卡里主动放车型技能 | 不是忘了有技能键 |
| 7 | 升车后能感知技能变了 | 「这台车技能不一样」 |

## 14. 数据草案

```text
PlayerProfile
  - gold
  - vehicleTier: 1..30
  - inventory: [{ itemId, level, count }]
  - stageStars: { [stageId]: 0..3 }
  - maxStageUnlocked

ItemDef
  - itemId            # 如 scrap_core（可先单一币种道具，靠 level 区分）
  - nameByLevel[]     # 或 name + "LvN"
  - buyPrice(level)
  - sellPrice = floor(buyPrice*0.5)

VehicleDef
  - tier, name, seats, baseSpeed, baseWidth
  - upgradeCost: { level, count }   # 升到本阶所需
  - skill: {
      id, name, desc,
      cooldown, chargesPerRun?,   # charges 空=仅 CD
      effectType, effectParams,   # dash / speedburst / iframe / discard ...
      fx                            # 可见反馈
    }

StageDef
  - id, goalDistance
  - dropLevel = min(30, ceil(id/5))
  - dropSpawns: [{ z, lane, itemId }]
  - absorbSpawns / hazards / checkpoints
  - starRules: { time3, minIntegrity3, ... }
  - goldBase

RunState
  - tempParts[]
  - pickedItems[]
  - vehicleTier                 # 开局带入（默认 1=赠送自行车）
  - skillCd, skillChargesLeft
  - skillBuffT / flags            # 技能持续效果
  - starProgress 指标…
```

**MVP 可先做「单一道具种类 + 仅 level 不同」**，降低美术与表数量；车阶名用表驱动。

## 15. 风险与原则

| 风险 | 应对 |
|------|------|
| 养成压过撞装 | 局内仍强制窄路丢件；广告钩子只打撞装 |
| 30×30 爆表 | 公式定价 + 单种类道具 + 换色车模 |
| 商城坏平衡 | 货架锁定在进度附近等级；卖出 50% |
| 开局不能玩 | **已冻结：赠送自行车** |
| 掉落交界歧义 | 冻结 `dropLevel = ceil(stageId/5)` |
| 技能变万能键 | 每车技能差异化；CD/次数限制；清不了致命大件 |
| 升车无感 | 换模 + 换技能，车库预告下一阶技能 |

| 原则 | 说明 |
|------|------|
| 临时件 ≠ 持久道具 | 命名、UI 分栏 |
| 星级驱动金币 | 鼓励重玩不是肝时间无目标 |
| 合成同构升车 | 玩家只学一套「两个合成一个」 |
| 形态可见 | 车阶换模 + 临时件改变轮廓 |
| 一车一技 | 技能是车型身份，闯关可主动放 |

## 19. 一页纸摘要

- **开局：** 赠送**自行车**（1 乘客）。  
- **局内：** 要不要撞？越大越强也越难过；**点技能**过险/抢时间。  
- **技能：** 每台车技能不同，闯关可释放（CD/次数）。  
- **关后：** 三星差金币；关内掉持久道具。  
- **商城：** 买；卖 **50%**。  
- **合成：** 2×LvN → 1×LvN+1（至 30）。  
- **车阶：** 1～30，升阶耗高级道具；升车=换模+换技能。  
- **掉落：** 每 5 关提升一阶道具等级。
