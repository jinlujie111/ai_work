# 拼车狂飙 · 美术需求 Brief

> 工程：`luyang` · 画布逻辑 **750×1334** · 品类：2.5D 公路闯关 + 轻养成  
> 视觉锚点：**夜沥青 + 警示琥珀黄 + 废铁金属感**（禁止默认紫渐变 / 奶油衬线风）  
> 原则：美术用 **底模 + 换色 / 挂件组合**，禁止按 30 车阶 × 30 道具手画 900 种

---

## 0. AI 能否自动生成？

| 层级 | AI 能做什么 | 不能替代什么 |
|------|-------------|--------------|
| **本文档 / 清单 / 规格** | ✅ 可自动维护、按版本扩关卡改 brief | — |
| **程序矢量 / Canvas 几何** | ✅ 载具轮廓、轮子、路段、简易特效可代码生成 | 精细品牌感、统一材质 |
| **AI 出图（图标/概念/贴图）** | ⚠️ 可出草稿与变体，需人工选图 + 统一风格 + 切透明底 | 挂点对齐、包体优化、微信审核观感 |
| **整套可上线 UI/局内资产** | ❌ 不能一键全自动无验收上线 | 可读性验收、交互热区、动画节拍 |

**推荐产线（个人主体）：**

1. **程序优先**：自行车 / 障碍 / 掉落先用 Canvas 画到「一眼能认」。  
2. **AI 补概念与图标**：主菜单氛围、道具品质框、技能图标出 4～8 变体 → 人选定 1。  
3. **定稿进包**：统一调色（琥珀黄 `#ffb020` 系）、透明 PNG、命名进 `assets/`。  
4. **禁止**：每关让 AI 全新大背景；道具 Lv1～30 各出一张互不相关的图。

代码侧可继续迭代矢量；出图侧用同一份 prompt 套（见 §7）。

## 2. 资产清单（细化）

### 2.1 局内场景

| 资产 | 规格要点 | 数量策略 | 优先级 |
|------|----------|----------|--------|
| 路面段（明暗交替） | 可纵向 tiling | 1 套 + 可选雨天换色 | P0 |
| 路肩 / 护栏 | 左右可重复 | 1 套 | P0 |
| 远景山 / 天际 | 横条层 | 1～2 | P0 |
| 车道线 | 虚线随 scroll | 1 | P0 |
| 检查点窄门 / 龙门架 | 「必须瘦身」可读 | 1～2 | P0 |
| 关卡特色摆件 | 废铁场 / 雨后 / 窄桥 / 高速 | 前 10 关各 ≤1 摆件，**不换整套场景** | P1 |

### 2.2 载具（最高优先级）

| 档位 | 代表 | 画法 | 数量 |
|------|------|------|------|
| V1 | 自行车 | 侧视或 3/4，双轮可读 | 精做 1 |
| V2～V3 | 电动车 / 摩托 | 同骨架换壳 | 2 |
| V4 | 三轮摩托 | 多一轮可辨 | 1 |
| V5～V8 | 微型车→皮卡 | 轿车骨架 + 顶/斗差异 | 4 |
| V9～V30 | 公式车 | **复用 8 底模 × 换色 / 贴花** | 0 新底模 |

每台车交付：

- 车库静止图 1  
- 行驶 2～4 帧（轮转 / 微抖即可）  
- 前后左右 **挂点坐标**（给临时零件）

### 2.3 临时零件（撞装，须「地上 + 车上」成对）

| id | 名称 | 视觉要求 |
|----|------|----------|
| `bumper` | 防撞杠 | 金属杠，挂头/尾 |
| `wide_tire` | 宽轮胎 | 车宽变化一眼可见 |
| `crate` | 货箱 | 后部堆高/加长 |

各需：**落地废铁** 1 + **挂接件** 1。颜色尽量对齐 `src/spec/parts.js`。

### 2.4 障碍与掉落

| 类型 | 视觉 | 数量 | 优先级 |
|------|------|------|--------|
| 可吸废铁 | 与零件对应 +「可吸」描边 | = 零件种数 | P0 |
| 非致命障碍 | 锥桶 / 路障 / 小坑 | 3 | P0 |
| 致命障碍 | 断桥 / 坑 / 大车尾 | 2～3 | P0 |
| 持久掉落箱 | 1 底图 + 稀有度描边 4 色；等级用字叠 | 1+描边 | P0 |
| 教学高亮环 | 程序绘制优先 | 0～1 | P0 |

### 2.5 特效（最小集）

| 事件 | 最小表现 |
|------|----------|
| 吸附 | 绿吸束 + 车身一胀 |
| 丢件 | 零件飞出 |
| 无敌 / 闪身 | 黄闪或残影 |
| 加速类技能 | 尾迹 |
| 撞毁 / 过热 | 红闪 + 简烟 |
| 三星 | UI 星弹出即可 |

先做通用 4 套（吸 / 丢 / 无敌 / 加速），车型技能以换色区分。

### 2.6 UI

| 界面 | 内容 |
|------|------|
| 主菜单 | Logo、主按钮、金币、当前车缩略 |
| HUD | 进度、技能、丢弃、暂停 |
| 路段选择 | 关卡、锁、星 |
| 背包 / 合成 | 格、数量、合成钮 |
| 商城 | 商品卡、买卖价 |
| 车库 | 车大图、技能、升阶 |
| 结算 | 星、金币、掉落列表 |
| 通用组件 | 弹窗底、主/次按钮、关闭 |

一套组件贯穿全站，禁止每页换风格。

### 2.7 图标

| 内容 | 策略 |
|------|------|
| 道具 Lv1～30 | **1 形 × 品质色阶 / 边框**；数字叠字，禁止 30 张无关插画 |
| 金币 | 1 |
| 技能 | 前 8 车各 1，其后复用 |
| 商店 / 分享图 | 上线前再做 |

## 4. 外包拆包顺序

1. **钉板（3～5 天）**：情绪板 + 主菜单 1 屏 + 局内 1 帧（自行车 + 废铁 + 窄门）。  
2. **可读性 P0**：V1 车 + 3 零件挂接 + 障碍 2 类 + 掉落箱 + HUD 关键钮。  
3. **成长外观**：V2～V8 + 车库大图 + 技能 8 图标。  
4. **包装**：结算 / 商城 / 背包组件 / 分享图。

## 5. 现状对照（验收缺口）

| 层 | 现状 | 缺口 |
|----|------|------|
| 程序几何 | 路、矢量自行车、可读吸/障/掉 | 正式贴图与挂件 |
| 零件 / 障碍 / 掉落 | Canvas 造型（绿圈废铁 / 锥·深坑 / 品质箱） | 换正式 PNG 时对齐挂点 |
| UI | CSS 夜路换皮 | 成套切图与图标 |
| 特效 | 描边闪 | 技能差异弱 |

**最小可上线顺序：** V1～V4 可读 → 吸/障/掉 三物 → 零件挂接 → HUD/结算 → 场景换装与特效。

---

## 6. 验收标准（可读性优先）

- [ ] 第 1 关 3 秒内能认出是自行车  
- [ ] 路上三种物（可吸 / 危险 / 掉落）无字也能分清  
- [ ] 装上宽胎 / 货箱后车外形明显变宽或变长  
- [ ] 窄门造型让人读出「过不去要丢件」  
- [ ] 主界面与局内同属一套夜路警示黄气质

## 7. AI 出图 Prompt 套（可选）

**共用后缀：**

```text
mobile game asset, WeChat minigame, 2.5D highway racer,
night asphalt, hazard amber accent #ffb020, scrap metal,
clean silhouette, transparent background, no text, no watermark,
consistent lighting, game-ready PNG
```

**自行车示例：**

```text
side view bicycle with rider silhouette, two clear wheels,
diamond frame, handlebar, game character vehicle sprite,
[共用后缀]
```

**掉落箱示例：**

```text
single loot crate icon, slightly isometric, metal straps,
rarity-ready plain base (no numbers), [共用后缀]
```

生成后人工：统一缩放到规格、去底、按 §3 命名入库；同一批只用同一 seed/风格锁（若工具支持）。
